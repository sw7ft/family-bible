# Quiet Bible — text sources

This app ships only public-domain English Bibles. No NIV, ESV, NASB, or other copyrighted text.

| ID | Translation | License |
|---|---|---|
| `webu` | World English Bible Updated | Public domain (eBible.org) |
| `bbe` | Bible in Basic English | Public domain |
| `kjv` | King James Version | Public domain in the United States |

Packed from `ringletech/webu-open-bible` and `thiagobodruk/bible` JSON dumps via `scripts/pack-bible.py`.
